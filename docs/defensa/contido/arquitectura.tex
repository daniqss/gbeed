\section{Desenvolvemento}

\begin{frame}{Arquitectura do hardware}
  \begin{columns}[c]
    \begin{column}{0.44\textwidth}
      \small
      \begin{itemize}

        \item Case todos os compoñentes están integrados nun único \textsc{SoC}, o Sharp SM83.
        
        \item Bus de datos de 8 bits e de direccións de 16 con \destacado{64\,KiB}
        de espazo direccionable.
        
        \item Ten E/S está mapeada en memoria, cada rexistro ou memoria ten o seu
        espazo reservado no mapa de memoria.
      
      \end{itemize}
    \end{column}

\begin{frame}{Arquitectura do emulador}
  \begin{columns}[c]
    \begin{column}{0.42\textwidth}
      \small
      \begin{itemize}

        \item O emulador divídese en tres módulos principais separados:
        un núcleo que se ocupa da lóxica da emulación en forma de librería
        e dous clientes que implementan a interface de usuario.

        \item Para empregar o núcleo, os clientes teñen que instanciar un \texttt{Dmg}
        e implementar un \texttt{Controller}.

        \end{itemize}
    \end{column}

\end{frame}

\begin{frame}[fragile]{O núcleo delega na implementación do cliente}
  \begin{columns}[c,onlytextwidth]
    \begin{column}{0.50\textwidth}
\begin{lstlisting}[language=Rust,basicstyle=\ttfamily\fontsize{7.8pt}{8.3pt}\selectfont,breaklines=false]
impl Dmg {
  pub fn run<C: Controller>(
      &mut self, controller: &mut C,
  ) -> Result<(), DmgError> {
      while self.cpu.cycles < 17556 {
          self.step(controller)?;
      }

      self.cpu.cycles = 0;
      controller.flush_buffer();

      Ok(())
  }
}
\end{lstlisting}
    \end{column}
    \begin{column}{0.48\textwidth}
      \begin{itemize}
        \item O núcleo implementa a lóxica de emulación e despreocúpase da implementación do cliente,
        que pasa un \texttt{Controller} como parámetro xenérico.

        \item Este \texttt{Controller} implementa as operacións do emulador que son dependentes do cliente.
        Deste xeito o núcleo queda libre de dependencias pero mantendo a capacidade de introducir comportamentos específicos do cliente.
      \end{itemize}
    \end{column}
  \end{columns}
\end{frame}
