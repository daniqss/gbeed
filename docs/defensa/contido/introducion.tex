\section{Introdución e obxectivos}

\begin{frame}{Xogar á Game Boy hoxe}
  \small
  \begin{columns}[t]
    \begin{column}{0.48\textwidth}
      \begin{block}{Hardware orixinal}
        \begin{itemize}
          \item É cada vez máis escaso, sendo hoxe máis un obxecto de
            coleccionismo que unha plataforma de xogos.

            \item Require mantemento e reparacións para funcionar correctamente
          e para suplir as demandas de ergonomía modernas 
        \end{itemize}
      \end{block}
    \end{column}
    \begin{column}{0.48\textwidth}
      \begin{block}{Alternativas comerciais}
        \begin{itemize}
          \item Consolas de emulación con SO de proposito xeral con hardware sobredimensionado.
          \item Montaxes \textsc{diy} sobre microcontroladores con mala accesibilidade para o usuario medio.
        \end{itemize}
      \end{block}
    \end{column}
  \end{columns}
\end{frame}


\begin{frame}{Obxectivos}
  \begin{alertblock}{Obxectivo xeral}
    Desenvolver un emulador da Game Boy orixinal (\textsc{dmg}-01) 
    portable e eficiente para ser empregado en todo tipo de contornas,
    ademais dunha construción de referencia con hardware accesible.
  \end{alertblock}

  \vspace{0.3em}

  \small
  \begin{columns}[t]
    \begin{column}{0.48\textwidth}
      \begin{itemize}
        \item Emular con precisión o modelo orixinal, o \textsc{dmg}-01.
        \item Validar os compoñentes contra as probas de referencia da comunidade.
        \item Garantir o funcionamento dos xogos máis populares do catálogo.
      \end{itemize}
    \end{column}
    \begin{column}{0.48\textwidth}
      \begin{itemize}
        \item Deseñar unha interface axeitada para contornas embebidas.
        \item Optimizar a execución en hardware de recursos limitados.
        \item Documentar unha construción de referencia reproducible por calquera persoa.
      \end{itemize}
    \end{column}
  \end{columns}
\end{frame}
